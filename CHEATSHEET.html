Tip  ./bin/recce = python3 -m recce. Use sudo for SYN/OS detection.

3Speed & filters

  • --fast — top-signal checks only
  • --aggressive — brute / nikto / dir-bust
  • --only http smb — restrict to named services
  • --unscanned — only ports not yet scanned
  • --workers N / --profile quick / --host-timeout
  • --resume — pick up interrupted run
  • --no-probes / --no-searchsploit
Debug  RECCE_DEBUG=1 for full tracebacks.
